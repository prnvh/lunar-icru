# lunar-icru

This repository is a research project on the reproducible intercomparison of lunar-propellant techno-economic models.

## Research question

When major lunar-propellant economic models are given the same physical and economic assumptions, do they converge on the same conclusion? If not, what causes the remaining disagreement?

## Current state

The repository currently contains a detailed research specification and project rules. It does not yet contain source documents, model reconstructions, parameter files, benchmarks, analysis code, or reproduction results.

- [Research specification](paper.md)
- [Project rules](rules.md)
- [Initial literature and evidence review](research/initial-literature-review.md)
- [Decision and activity log](log.md)

The review is an initial evidence map, not a claim that any candidate model has already been reconstructed or independently validated. The sources and inclusion decisions should be version-locked as the project progresses.
